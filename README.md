# مِهرشمار

نسخهٔ وب‌اپلیکیشن قابل نصب (PWA) و آفلاینِ مِهرشمار.

## نصب روی Android
در Chrome صفحهٔ منتشرشده را باز کنید و از منوی مرورگر گزینهٔ **Install app** یا **Add to Home screen** را انتخاب کنید.

## آفلاین
پس از اولین بارگذاری آنلاین، فایل‌های اصلی در Service Worker ذخیره می‌شوند و برنامه پس از آن آفلاین نیز باز می‌شود.

## انتقال داده‌ها
عبارت‌ها و تاریخچه در حافظهٔ محلی همان مرورگر و همان مبدأ ذخیره می‌شوند. برای انتقال داده از نسخهٔ قبلی، در نسخهٔ قدیمی «دریافت فایل پشتیبان» را بزنید؛ سپس در نسخهٔ منتشرشده «بازیابی پشتیبان» را انتخاب کنید.

## انتشار با GitHub Pages
از Settings → Pages، گزینهٔ Deploy from a branch را انتخاب کنید، شاخهٔ `main` و پوشهٔ `/(root)` را تنظیم و ذخیره کنید.
